프로그래머스에서 Python 문제를 풀면, 정답 코드가 자동으로 내 GitHub 저장소에 커밋됩니다.

매번 코드를 복사해서 붙여넣고, 파일 이름을 정하고, 커밋 메시지를 쓰는 일을 더 이상 하지 않아도 됩니다.


■ 주요 기능

1. 정답 자동 업로드
프로그래머스에서 '제출 후 채점하기'를 눌러 정답 판정을 받으면, 에디터에 작성한 코드를 그대로 읽어 GitHub 저장소에 커밋합니다. 파일 상단에는 문제 제목, 난이도, 문제 링크, 작성자, 작성일이 주석으로 함께 기록됩니다.

2. 393문제 진행률 추적
코딩테스트 입문 100문제, 코딩 기초 트레이닝 123문제, Lv.1~Lv.5와 레벨7 챌린지 170문제. 총 393문제의 진행 상황을 Chrome 사이드 패널에서 확인합니다. 브라우저 오른쪽에 붙어 있어 문제를 풀면서도 계속 볼 수 있습니다.

3. 다음 문제 추천
아직 풀지 않은 문제 중 가장 쉬운 것을 추천합니다. 어디서부터 다시 시작해야 할지 고민하지 않아도 됩니다.

4. 문제와 코드로 바로 이동
목록에서 문제 이름을 누르면 프로그래머스 문제 페이지가 열립니다. 이미 푼 문제는 오른쪽 GitHub 버튼을 눌러 내 저장소의 풀이 파일로 바로 이동할 수 있습니다.

5. 간편한 GitHub 연결
개인 액세스 토큰(PAT)을 직접 발급할 필요가 없습니다. 'GitHub로 로그인'을 누르면 기기 인증 코드가 자동으로 입력되고, 승인(Authorize) 버튼만 직접 눌러주면 연결이 끝납니다.

■ 개인정보 보호

- 개발자가 운영하는 서버가 없습니다. 어떤 데이터도 개발자에게 전송되지 않습니다.
- GitHub 액세스 토큰은 브라우저 로컬 저장소에만 보관되며, 외부로 나가지 않습니다.
- 통신 대상은 GitHub(api.github.com, github.com/login)와 프로그래머스뿐입니다.
- 광고, 추적, 분석 도구를 일절 사용하지 않습니다.


■ 사용 방법

1. 툴바 아이콘을 눌러 사이드 패널을 열고 이름을 입력합니다.
2. 'GitHub로 로그인'을 눌러 계정을 연결합니다.
3. 저장소를 선택하거나, '새 저장소 만들기'로 python-algorithm 저장소를 생성합니다.
4. 프로그래머스에서 Python으로 문제를 풀고 제출합니다. 정답이면 자동으로 커밋됩니다.


■ 참고 사항

- Python(python3)으로 제출한 경우에만 업로드됩니다. 다른 언어나 SQL 문제는 업로드하지 않습니다.
- 공개(public) 저장소만 지원합니다.
- Chrome 114 이상이 필요합니다. (사이드 패널 기능)
- 승인(Authorize) 버튼은 사용자가 직접 눌러야 합니다. 확장 프로그램이 대신 누르지 않습니다.
- 오픈소스입니다. 소스 코드를 직접 확인하실 수 있습니다.
