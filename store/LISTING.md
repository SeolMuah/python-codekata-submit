## 2. 개인정보 보호 관행 탭

### 단일 목적 설명

```
프로그래머스에서 Python으로 제출해 정답 판정을 받은 풀이 코드를 사용자가 연결한 GitHub 저장소에
자동으로 커밋하고, 그 진행률을 브라우저 사이드 패널에 표시합니다.
```

### 권한 사유

| 권한 | 사유 (붙여넣기) |
|---|---|
| `storage` | 문제 풀이 진행률, 사용자가 입력한 이름, 선택한 GitHub 저장소, GitHub 액세스 토큰을 브라우저에 저장하기 위해 필요합니다. |
| `sidePanel` | 진행률과 문제 목록을 브라우저 사이드 패널에 표시하기 위해 필요합니다. |
| `alarms` | GitHub 기기 인증(Device Flow)이 완료될 때까지 토큰 발급 여부를 주기적으로 확인하기 위해 필요합니다. Manifest V3 서비스 워커는 유휴 상태에서 종료되므로, 알람 없이는 사용자가 승인을 늦게 누를 때 로그인이 완료되지 않습니다. |
| `school.programmers.co.kr` | 문제 채점 결과(정답/오답)를 감지하고, 정답일 때 에디터에 작성된 풀이 코드를 읽기 위해 필요합니다. |
| `api.github.com` | 사용자의 저장소 목록을 조회하고, 저장소를 생성하고, 풀이 파일을 커밋하기 위해 필요합니다. |
| `github.com/login/*` | GitHub OAuth 기기 인증을 수행하고, 기기 인증 코드를 입력 화면에 자동으로 입력하기 위해 필요합니다. |
| 원격 코드 사용 | **아니요.** 모든 코드가 패키지에 포함되어 있으며 외부 스크립트를 내려받아 실행하지 않습니다. |

### 데이터 사용 공개

**수집한다고 체크할 항목** (사용자 기기 밖으로 전송되므로):

- ✅ **인증 정보** — GitHub OAuth 액세스 토큰 (GitHub API 인증에만 사용)
- ✅ **웹사이트 콘텐츠** — 사용자가 프로그래머스에 작성한 풀이 코드 (사용자 본인의 GitHub 저장소로만 커밋)

**체크하지 않을 항목:** 개인 식별 정보 / 건강 정보 / 금융 및 결제 정보 / 인증 정보를 제외한 개인 통신 / 위치 / 웹 방문 기록 / 사용자 활동

**인증서 3개 모두 체크:**

- ✅ 승인된 사용 사례가 아닌 한 제3자에게 데이터를 판매하거나 이전하지 않습니다
- ✅ 항목의 단일 목적과 관련 없는 용도로 데이터를 사용하거나 이전하지 않습니다
- ✅ 신용도 판단이나 대출 목적으로 데이터를 사용하거나 이전하지 않습니다

## 심사에서 걸릴 수 있는 지점

1. **개인정보처리방침 URL 누락** — 인증 정보를 다루므로 없으면 거부됩니다. 먼저 푸시하세요.
2. **host_permissions 사유** — 위 표의 문구를 그대로 쓰면 충분합니다. "필요해서"처럼 모호하면 되돌아옵니다.
3. **저장소 이름** — 홈페이지/지원 URL의 저장소 이름이 아직 `python-codekata-submit` 입니다.
   코드와 문서에서는 그 단어를 모두 지웠지만 저장소 이름은 그대로입니다. 신경 쓰이시면
   GitHub에서 저장소 이름을 바꾼 뒤(리다이렉트가 자동 생성됩니다) URL을 갱신하세요.
4. **최초 심사 기간** — 보통 며칠 걸립니다. 이후 버전 업데이트는 더 빠릅니다.
